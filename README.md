# ANA特典航空券 空席候補検索・LINE通知ツール

SAMURAI ENGINEERのPython学習課題として制作した、ANA国際線特典航空券の**空席候補日を確認し、LINEへ通知する**ツールです。

> **重要**：本ツールが取得するのはANAのカレンダー上の空席表示です。大人2名分の予約成立、往復旅程の成立、現地宿泊日数を保証するものではありません。ANAの利用条件に配慮し、検索回数を制限しています。

## 1. 開発目的

希望する往復日程を探すためにANAのサイトで日付を繰り返し切り替える手間を減らし、候補がある時期を把握しやすくすることを目的としています。

希望の出発日差（4〜5日）が見つからない場合にも、検索中に確認できた**参考候補**をLINEへ通知します。

## 2. 検索条件

| 項目 | 内容 |
| --- | --- |
| 往路 | 成田（NRT）→ オークランド（AKL） |
| 復路 | オークランド（AKL）→ 成田（NRT） |
| 人数 | 大人2名 |
| 種別・クラス | 国際線特典航空券・エコノミー |
| 希望日程 | 往路と復路の**出発日差**4〜5日 |
| 空席表示 | 前後3日比較を利用 |
| 検索基準日 | 実行日のおよそ2か月後から、7日間隔 |
| 実行上限 | 最大3回／起動（アクセス制限等では途中停止） |

※「出発日差」は実際のオークランドでの宿泊数とは異なります。

## 3. 実装した機能

1. PlaywrightによるANA予約サイトへのログイン・検索条件の自動入力
2. 大人2名・特典エコノミーなどの設定値の確認、検索画面に戻った際の再設定
3. 空席カレンダーから往路・復路の空席表示日を取得
4. 出発日差4〜5日の候補を抽出・重複除去
5. **希望日程以外にも空席表示がある場合、参考候補として整理**
6. 検索日時・検索回数・候補日程をLINE Messaging APIで通知（送信前に確認あり）
7. 条件一致候補をCSVに保存。候補0件の場合は古いCSVを上書きしない
8. 一部の案内ダイアログへの対応と、混雑・アクセス制限・判定不能時の停止

### LINE通知例

```text
【ANA特典航空券・検索結果】
希望の出発日差4～5日の候補は見つかりませんでした。

【参考：4～5日差以外の空席表示】
往路 2027-01-21 → 復路 2027-01-24（出発日差3日）
往路 2027-01-28 → 復路 2027-02-04（出発日差7日）

※カレンダー上の空席表示を組み合わせた参考情報です。
※往復旅程としての予約可否は未確認です。
```

上記の日程は過去の実行ログに基づく**表示例**であり、現在の空席を示しません。

## 4. 使用技術

- **Python**：検索・日付判定・結果集約
- **Playwright / Chromium**：ブラウザ操作とDOMの読み取り
- **python-dotenv**：ローカル環境変数の読み込み
- **CSV**：条件一致候補の保存
- **LINE Messaging API**：検索結果のプッシュ通知
- **GitHub / GitHub Actions / Cloudflare Workers**：別系統のLINE遠隔起動テスト

## 6. 実行方法（Windows）

Pythonと必要なライブラリ、PlaywrightのChromiumを用意します。

```powershell
py -m pip install playwright python-dotenv
py -m playwright install chromium
```

実行に必要な環境変数を、PC内の `.env` に設定します。**実際の値をGitHubにアップロードしないでください。**

```dotenv
ANA_PASSWORD=（自身のANAパスワード）
LINE_CHANNEL_ACCESS_TOKEN=（自身のLINEアクセストークン）
LINE_USER_ID=（自身のLINEユーザーID）
```

※ANAの会員番号等については、既存のログイン処理とローカル環境の設定を確認してください。公開用READMEに実際の認証情報は記載しません。

PowerShellで実行：

```powershell
cd C:\GitHub\kadai_self
py ana_award_submission_with_alternatives.py
```

または **`ANA空席検索_参考候補付き.bat`** をダブルクリックします。このBATは `C:\GitHub\kadai_self` を前提としています。別の場所に保存する場合はBAT内のパスを変更してください。

検索終了後、ターミナルに通知内容が表示され、`y` を入力するとLINEへ送信します。処理終了時にEnter入力を求める場合があります。**現状はPC上での手動起動・対話操作が必要です。**

## 9. 制限事項と安全対策

- カレンダーの「空席あり」は、往復予約の成立や大人2名分の空席を保証しません。
- 航空会社、便名、必要マイル数、税金・燃油サーチャージは取得しません。
- 現地到着時刻・出発時刻からの実宿泊数は算出しません。
- 起動時だけ検索し、定期実行・常時監視・自動再起動は行いません。
- ANAサイトに過度な負荷をかけないよう、1回の起動につき検索上限を3回に設定しています。利用規約やアクセス制限を尊重してください。
- `.env`、認証情報、個人情報が映った画像・実行ログ、ブラウザプロフィールは公開しないでください。
- GitHubに登録する際は、`.gitignore` に `.env` や個人情報を含むファイルの除外設定を確認してください。
